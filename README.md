## 功能

- 固定主题、跟随 Obsidian 明暗、按时间切换，按模式显示相关设置。
- 浅色/深色或白天/夜晚独立选择角色，显示当前生效状态。
- 每个角色分别保存主图清晰度、正文宽度、四角卡片和动效参数。
- 暂停或卸载时恢复接管前的外观片段；系统减少动态效果优先。

## 这是源码仓库，不是含素材的安装包

本仓库不包含个人笔记、笔记库历史、角色图片、预览图、内联图片的主题 CSS 或个人设置。`registry.json` 仅记录主题名称、素材路径和校验值。

构建需要你已合法持有并在本地准备好的主题资源。当前适配已有本地主题库的 `外观配置/` 目录布局，具体文件见 `registry.json` 的 `source` 字段。不自动下载上游素材。

使用 Node.js 运行（无 npm 依赖）：

```bash
node test.cjs
node build.cjs "/你的/Obsidian笔记库路径"
```

输出至 `dist/character-theme-studio/`。构建器只读取指定笔记库的主题资源，不更改该笔记库。把输出目录里的文件复制到该笔记库 `.obsidian/plugins/character-theme-studio/`，更新时保留已有 `data.json`。在 Obsidian 第三方插件设置中启用。建议配合 Minimal 基础主题。

构建产物包含角色素材，仅本地个人使用，已忽略 `dist/`，不要公开上传。

## 切换方式

- 固定主题：只显示一个角色选择。
- 跟随 Obsidian 明暗：浅色和深色主题分别设置；不强制改变 Obsidian 明暗偏好。
- 按时间切换：默认 07:00 白天、19:00 夜晚，按本机时区每 30 秒检查。休眠时不唤醒，恢复后检查。

手动命令面板选择角色会返回固定模式。切换模式不清除之前的角色选择。角色参数在插件设置中即时调节，无需手改 CSS。

## 兼容与安全

插件不联网、不读取笔记正文、不执行上游 JavaScript。作为社区插件，技术上仍有笔记库访问能力，请只启用可信代码。

片段兼容层依赖本机 `customCss.enabledSnippets` 和 `setCssEnabledStatus` 私有接口；应用升级后接口不匹配会停止接管并报错。独立浮动窗口外观未保证。角色素材权利归原权利人，见 NOTICE.md。
